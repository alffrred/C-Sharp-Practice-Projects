## 🚀 Included Projects

### Space Mission Simulator
A terminal-based resource management strategy game written in C# for Dokuz Eylül University Computer Engineering coursework.

#### Key Features
- **Resource Management:** Balance Fuel, Oxygen, Energy, Spaceship Health, and Credits across turn-based days.
- **Exploration & Mining System:** Travel to and explore planets (Mercury, Mars, Europa) with conditional unlock requirements.
- **Supply Station:** Trade collected minerals, repair the spaceship, and manage life-support resources.
- **Strict Constraints:** Implemented using pure base structures (`if-else`, `switch-case`, `while`) without forbidden collections or methods.

dotnet build
